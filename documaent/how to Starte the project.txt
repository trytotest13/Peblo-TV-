Phase 0: Understand Before Coding (1–2 hrs)

    Read the challenge doc 2–3 times — list every explicit requirement + implicit ones (validation, error handling, docs).
    **Map requirements to the JD stack FastAPI + PostgreSQL/Supabase + React/TS + Docker. Don't use anything outside the stack — they're testing stack fit.
    Check evaluation criteria — usually: working code > code quality > architecture > extras. Prioritize in that order.

Phase 1: Design First (1 hr)

    Sketch data models (tables, relationships, indexes) on paper.
    Sketch API endpoints (REST, resource naming, status codes).
    If the challenge involves CMS/admin features → plan roles/permissions (they explicitly mention User Access Controls + Audit Logging in the JD — likely themes).
    Write a short DESIGN.md — this alone separates you from most candidates.

Phase 2: Backend Core (3–4 hrs)

    FastAPI project scaffold: routers / services / models / schemas separation.
    Pydantic schemas for request/response validation.
    PostgreSQL via SQLAlchemy (async) or Supabase client; write migrations (Alembic) — JD stresses zero-downtime migration thinking.
    Auth: JWT with role-based access control.
    Write tests for critical paths (pytest) — even 5–6 good tests stand out.

Phase 3: Frontend (2–3 hrs)

    React 18 + TypeScript + Vite + Tailwind + TanStack Query.
    Only build what's asked — one or two clean screens (list + form + detail is common).
    Zod validation on forms (JD explicitly uses React Hook Form + Zod).

Phase 4: DevOps Polish (1–2 hrs)

    Dockerfile (multi-stage) + docker-compose.yml (app + db + redis if needed).
    GitHub Actions workflow: lint → test → build (even simple = big differentiator; they run CI/CD daily).
    Proper README.md: setup in 3 commands, architecture diagram, decisions/tradeoffs section.

Phase 5: Review & Submit (1 hr)

    Lint (ruff/black, eslint), remove dead code, secrets out of repo (use .env.example).
    Name file: Full_Stack_Development_challenge_<yourname>.zip
    Submit via the Google Form, select "Full Stack Development."
